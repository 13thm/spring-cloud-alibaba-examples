# 学习文档：integrated-gateway（网关模块）

> 位置：`integrated-example/integrated-gateway`（端口 30010）—— 整合示例的统一流量入口，
> 集成三大能力：**Gateway 动态路由（配 Nacos）+ Sentinel 网关限流 + CORS 跨域**。

---

## 一、这个模块做了什么

只有 2 个 Java 文件 + 1 份本地 yml，却承担了整个系统的"前门"职责：

| 文件 | 作用 |
|---|---|
| `GatewayApplication` | 启动类，`@EnableDiscoveryClient` 接入 Nacos 发现 |
| `GatewayConfig` | **核心**：Sentinel 网关三件套 + 限流规则 + 自定义限流响应 + CORS 过滤器 |
| `application.yaml` | 本地只配端口和 Nacos 地址，**路由规则全部在 Nacos** |

### 路由全景（规则存于 Nacos 的 integrated-gateway.yaml）

```
浏览器/前端 ──► :30010 网关
   ├─ /order/create    ──lb──► integrated-order     (下单：Seata 全局事务入口)
   ├─ /storage/        ──lb──► integrated-storage   (查库存)
   ├─ /account/        ──lb──► integrated-account   (查余额)
   ├─ /praise/rocketmq ──lb──► integrated-provider  (点赞：MQ 削峰)
   ├─ /praise/sentinel ──lb──► integrated-provider  (点赞：★此路由被限流 5 QPS)
   └─ /praise/query    ──lb──► integrated-consumer  (查点赞数)
```

### 动态路由的关键
`spring.config.import: optional:nacos:integrated-gateway.yaml` —— 网关监听 Nacos 配置变化，**改路由不用重启**。

### Sentinel 限流演示目标
`GatewayFlowRule("praiseItemSentinel").setCount(5).setIntervalSec(1)`：对 `/praise/sentinel` 路由限 1 秒 5 次，超出返回 `"此接口被限流了"`。

## 二、需要学习的知识点

1. **Spring Cloud Gateway 基础**
   - Route（路由）/ Predicate（谓词）/ Filter（过滤器）三概念；
   - `lb://服务名` 与 Nacos 服务发现 + 负载均衡的配合；
   - 基于 WebFlux/Reactor 响应式栈（返回 `Mono`），与 MVC 的编码差异。
2. **动态路由**：`spring.config.import` 整合 Nacos 配置中心，配置热更新原理（监听 Nacos 推送 → 刷新路由定义）。
3. **Sentinel 网关流控**（`sentinel-adapter-gateway`）
   - 标准三件套写法：`SentinelGatewayFilter`（入口）+ `SentinelGatewayBlockExceptionHandler`（异常出口）+ `GatewayRuleManager.loadRules`（规则）；
   - `GatewayFlowRule` 按路由 ID 限流 vs 普通 `FlowRule` 按资源限流的区别；
   - `GatewayCallbackManager.setBlockHandler` 自定义限流响应体。
4. **CORS 跨域**：网关层统一处理；`allowCredentials(true)` 必须搭配 `addAllowedOriginPattern("*")` 的原因。
5. **Bean 顺序**：`@Order(Ordered.HIGHEST_PRECEDENCE)` 保证 Sentinel 过滤器最先执行。

## 三、学习目的

- 掌握微服务**统一入口**的标准建法：路由收敛、限流兜底、跨域收口都在网关一层完成；
- 理解"配置中心驱动"的动态路由——生产上改路由/改限流规则不发版的运维价值；
- 学会 Sentinel 网关限流的完整接线方式，这是应对突发流量（秒杀、爬虫）的第一道闸。

## 四、以后怎么用

1. **新项目网关脚手架**：本模块的 `GatewayConfig` 可直接当模板抄；路由规则按业务追加到 Nacos 配置。
2. **限流规则进阶**：示例用代码写死规则，生产建议接 **Nacos 数据源 + Sentinel Dashboard**，实现控制台可视化推规则。
3. **常见扩展**（按需加）：
   - 全局鉴权过滤器（JWT 校验 GlobalFilter）；
   - 灰度路由（按 header/权重分流）；
   - 网关层聚合日志/链路追踪头注入。
4. **部署提示**：网关是无状态服务，可多实例横向扩容；本示例提供了 Dockerfile/docker-compose/Helm 三种部署产物可直接参考。
