## 🗺️ 推荐学习顺序与依赖关系

```
① provider(靶子)──► ② consumer(基础调用)──► ③ sclb(负载均衡/熔断进阶)
      │                                              │
      └──────────────► ⑥ reactive(响应式调用)◄──────┘(复用 provider)
      
④ config-server ──► ⑤ config-client   (独立主线:配置中心,与上面互不依赖)
```

- **第一周路线**:① → ② → ③,打通"注册/发现/调用/负载均衡/熔断"主干
- **第二周路线**:④ → ⑤,搞懂配置中心;有空再啃 ⑥(响应式)

## 🧠 知识地图(全家族覆盖)

- **Nacos**:服务注册时序、临时实例心跳(5s/15s/30s)、Namespace/Group/Service/Instance 模型、metadata 元数据(zone/灰度)
- **调用**:RestTemplate+@LoadBalanced / OpenFeign(声明式+fallback)/ WebClient(响应式)
- **负载均衡**:SCLB 替代 Ribbon、@LoadBalancerClient 按服务定制、子上下文机制、自定义策略、zone-preference
- **熔断限流**:Sentinel 资源名、UrlCleaner 清洗、flowrule/degraderule、Feign 整合
- **配置中心**:Git 后端、bootstrap 时序、discovery 找 configserver、@RefreshScope 刷新
- **响应式**:Netty 事件循环、Mono/Flux、ReactiveDiscoveryClient、Gateway 前置知识

## ⚠️ 全家族共同的坑 0(先修才能跑)

官方模块的 parent 链指向根 pom `com.alibaba.cloud:spring-cloud-alibaba-examples:${revision}`,
但当前仓库根 pom 已被替换为 `com.thm.cloud:...:1.0-SNAPSHOT` 空壳(无 revision、无 BOM)。
**修复**:根 pom 补 `<revision>` 属性 + dependencyManagement 引入三大 BOM
(Spring Boot 3.2.x / Spring Cloud 2023.0.x / Spring Cloud Alibaba 2023.0.x)。详见 provider 文档坑 0。

```
Nacos Server (8848)

```
